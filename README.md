## 프로젝트 개요

오디오 파일을 앱에 추가하면 Apple Speech Recognition이 자동으로 문장을 인식하고 타임스탬프를 부여합니다. 생성된 스크립트의 문장을 탭하면 해당 구간이 반복 재생되어 쉐도잉 연습에 최적화된 환경을 제공합니다. 문장 텍스트와 구간 시간은 직접 편집할 수 있습니다.

## 기술 스택

| 구분 | 기술 |
|------|------|
| 플랫폼 | iOS 26.2+ |
| 언어 | Swift 6.0 |
| UI | SwiftUI |
| 오디오 | AVFoundation (AVAudioPlayer) |
| 음성 인식 | Speech framework (SFSpeechRecognizer, en-US) |
| 아키텍처 | MVVM (ObservableObject + @MainActor) |
| 동시성 | Swift Concurrency (async/await, Task) |

## 프로젝트 구조

```
ShadowingApp/
├── ShadowingApp.swift          # 앱 진입점
├── ContentView.swift           # 전체 UI (목록, 재생, 스크립트 뷰)
├── AudioPlayerModel.swift      # 오디오 재생 상태 및 플레이리스트 관리
├── ScriptAnalyzer.swift        # 음성 인식 및 문장 세그먼트 처리
└── Info.plist                  # 앱 설정 및 권한 선언
```

## 주요 기능

**오디오 재생 및 플레이리스트**
- 로컬 오디오 파일 불러오기 (다중 선택 지원)
- 재생 속도 조절 (0.5×, 0.75×, 1.0×, 1.5×, 2.0×)
- 5초 앞/뒤 이동
- 꾹 눌러 다중 선택 후 선택 트랙만 반복 재생

**웨이브폼 시각화**
- 60개 바 기반 실시간 웨이브폼 렌더링
- 탭으로 원하는 위치로 즉시 이동
- 구간 반복 중 활성 구간 하이라이트 표시

**구간 반복 (쉐도잉 핵심 기능)**
```
문장 탭 → 해당 구간 자동 반복 → 화면 탭 또는 구간 취소 버튼으로 해제
```
- 스크립트 문장을 탭하면 해당 구간 무한 반복 재생
- 반복 횟수 설정 가능 (기본: 9999회)
- 현재 재생 중인 문장 실시간 하이라이트

**스크립트 자동 분석**
- SFSpeechRecognizer 기반 음성→텍스트 변환 (en-US 고정)
- 묵음 구간(0.7초 이상), 단어 수(12개 이상), 문장부호 기준으로 자동 분리
- 축약형 인식 오류 자동 보정 (예: `dont` → `don't`)

**스크립트 편집**
- 문장 텍스트 수정
- MiniWaveformEditor로 시작/종료 시간 드래그 조절
- 문장 추가 / 삭제 / 드래그로 순서 변경
- 편집 시트 내 미리듣기 지원

## 설치 및 실행

**요구 사항**
- Xcode 26.3 이상
- iOS 26.2 이상 기기 또는 시뮬레이터
- Apple Developer 계정

```bash
# 저장소 클론
git clone <repository-url>
cd ShadowingApp
```

1. `ShadowingApp.xcodeproj`를 Xcode에서 엽니다.
2. **Signing & Capabilities**에서 개발 팀을 본인 계정으로 변경합니다.
3. 실기기 또는 시뮬레이터를 선택하고 빌드합니다 (`Cmd+R`).

## 권한 설정

앱 최초 실행 시 다음 권한을 요청합니다. `Info.plist`에서 사용자에게 표시될 설명 문구를 직접 작성해주세요.

```
NSMicrophoneUsageDescription       # 마이크 접근
NSSpeechRecognitionUsageDescription  # 음성 인식
```

## 사용 방법

1. `+` 버튼을 눌러 오디오 파일을 추가합니다.
2. 목록에서 트랙을 탭하면 재생 화면으로 이동합니다.
3. **음성 분석 시작** 버튼을 눌러 스크립트를 자동 생성합니다.
4. 생성된 문장을 탭하면 해당 구간이 반복 재생됩니다.
5. 재생 화면 빈 곳을 탭하거나 **구간 취소** 버튼을 누르면 반복이 해제됩니다.
6. **편집** 버튼으로 문장 텍스트와 구간 시간을 수정할 수 있습니다.

## 한계 및 개선점

- SFSpeechRecognizer는 en-US로 고정되어 있어 타 언어 오디오는 인식 정확도가 낮음
- 긴 오디오 파일의 경우 분석 시간이 길어질 수 있음
- 문장 자동 분리 기준(묵음·단어 수·문장부호)이 콘텐츠 유형에 따라 부정확할 수 있어 수동 편집 필요
- 스크립트 데이터가 앱 재시작 시 초기화됨 → 영구 저장 기능(CoreData / SwiftData) 추가 필요
