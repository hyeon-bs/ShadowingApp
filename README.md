# ShadowingApp

오디오 파일을 불러와 문장을 자동 분석하고, 구간 반복 재생과 스크립트 편집 기능을 제공하는 영어 쉐도잉 학습 iOS 앱.

## 프로젝트 개요

오디오 파일을 앱에 추가하면 Apple Speech Recognition이 자동으로 문장을 인식하고 타임스탬프를 부여합니다. 생성된 스크립트의 문장을 탭하면 해당 구간이 반복 재생되어 쉐도잉 연습에 최적화된 환경을 제공합니다. 문장 텍스트와 구간 시간은 직접 편집할 수 있습니다.


## v2.1 변경 사항 (안정성 개선)

재생 안정성과 코드 품질을 전반적으로 개선했습니다.

**버그 수정**
- 트랙 재생 완료 후 두 번째 반복에서 다른 트랙이 재생되는 문제 수정
- 벌크 삭제 시 현재 재생 중인 트랙 인덱스가 어긋나는 문제 수정

**안정성 개선**
- 트랙 전환 시 이전 웨이브폼/duration 비동기 작업 취소 처리 추가
- 타이머 콜백 내 플레이어 nil safety 강화
- 재생 완료 delegate에서 sleep 후 URL 및 플레이어 유효성 재검증
- TrackDetailView 진입 시 Task 취소 및 인덱스 범위 재검증
- 개별/벌크 삭제 시 인덱스 bounds check 추가

**코드 정리**
- 전체 파일에서 불필요한 주석 및 데드코드 제거
- MARK 구분자와 구조적 주석만 유지

## v2 변경 사항

재생 목록의 편집 모드와 다중 선택 반복재생 흐름을 전면 개선했습니다.

**편집 모드 (다중 선택)**
- 목록 항목을 꾹 눌러 편집(선택) 모드 진입
- 헤더에 취소 버튼, 하단에 전체선택 / 전체해제 버튼 추가
- 기존 번호 아이콘이 선택 모드에서는 체크 버튼으로 전환
- 체크 버튼 영역에서 위아래 드래그로 여러 항목을 연속 선택/해제
- 편집 모드에서는 트랙 상세 화면 이동을 차단하고 체크/삭제만 가능

**다중 선택 반복재생**
- 선택 후 재생하면 일반 재생 화면으로 전환, 하단에 앞 / 멈춤 / 뒤 컨트롤 제공
- 반복재생 중인 선택 항목은 초록색, 현재 재생 중인 항목은 볼드로 표시
- 멈춤 버튼으로 완전 초기화

**기타**
- 스크롤과 드래그 제스처 충돌 해결 — 드래그 제스처를 왼쪽 오버레이 영역으로 분리

## 기술 스택

| 분류 | 기술 |
|------|------|
| 플랫폼 | iOS 26.2+ |
| 언어 | Swift 6.0 |
| UI | SwiftUI |
| 오디오 | AVFoundation (AVAudioPlayer) |
| 음성 인식 | Speech framework (SFSpeechRecognizer, en-US) |
| 아키텍처 | MVVM (ObservableObject + @MainActor) |
| 동시성 | Swift Concurrency (async/await, Task) |

## 프로젝트 구조

```
ShadowingApp/
├── ShadowingApp.swift          # 앱 진입점
├── ContentView.swift           # 전체 UI (목록, 재생, 스크립트 뷰)
├── AudioPlayerModel.swift      # 오디오 재생 상태 및 플레이리스트 관리
├── ScriptAnalyzer.swift        # 음성 인식 및 문장 세그먼트 처리
├── PersistenceManager.swift    # 로컬 영구 저장 (재생목록, 오디오, 스크립트)
└── Info.plist                  # 앱 설정 및 권한 선언
```

## 주요 기능

**오디오 재생 및 플레이리스트**
- 로컬 오디오 파일 불러오기 (다중 선택 지원)
- 재생 속도 조절 (0.5×, 0.75×, 1.0×, 1.5×, 2.0×)
- 5초 앞/뒤 이동
- 꾹 눌러 다중 선택 후 선택 트랙만 반복 재생

**웨이브폼 시각화**
- 60개 바 기반 실시간 웨이브폼 렌더링
- 탭으로 원하는 위치로 즉시 이동
- 구간 반복 중 활성 구간 하이라이트 표시

**구간 반복 (쉐도잉 핵심 기능)**
- 스크립트 문장을 탭하면 해당 구간 무한 반복 재생
- 반복 횟수 설정 가능 (기본: 9999회)
- 현재 재생 중인 문장 실시간 하이라이트

**스크립트 자동 분석**
- SFSpeechRecognizer 기반 음성→텍스트 변환 (en-US 고정)
- 묵음 구간(0.4초 이상), 단어 수(8개 이상), 문장부호 기준으로 자동 분리
- 축약형 인식 오류 자동 보정 (예: `dont` → `don't`)

**스크립트 편집**
- 편집 버튼으로 편집 모드 진입/해제 (편집 모드에서는 재생 정지)
- 편집 모드에서 문장 행을 탭하면 팝오버로 편집 / 삭제 선택
- 편집 시트에서 문장 텍스트 수정 + MiniWaveformEditor로 시작/종료 시간 드래그 조절
- 편집 모드에서만 `+` 버튼으로 신규 문장 추가
- 편집 시트 내 미리듣기 지원

**로컬 영구 저장**
- 재생목록, 오디오 파일, 트랙별 스크립트를 앱 전용 디렉토리(Application Support)에 JSON으로 영구 저장
- 앱 재시작 시 재생목록과 분석된 스크립트 자동 복원
- 오디오 파일이 실제로 존재하는 트랙만 재생목록에 표시하여 데이터 정합성 유지


## 설치 및 실행

**요구 사항**
- Xcode 26.3 이상
- iOS 26.2 이상 기기 또는 시뮬레이터
- Apple Developer 계정

```bash
git clone <repository-url>
cd ShadowingApp
```

1. `ShadowingApp.xcodeproj`를 Xcode에서 엽니다.
2. **Signing & Capabilities**에서 개발 팀을 본인 계정으로 변경합니다.
3. 실기기 또는 시뮬레이터를 선택하고 빌드합니다 (`Cmd+R`).

## 사용 방법

1. `+` 버튼을 눌러 오디오 파일을 추가합니다.
2. 목록에서 트랙을 탭하면 재생 화면으로 이동합니다.
3. **음성 분석 시작** 버튼을 눌러 스크립트를 자동 생성합니다.
4. 생성된 문장을 탭하면 해당 구간이 반복 재생됩니다 (같은 문장을 다시 탭하면 해제).
5. 재생 화면 빈 곳을 탭하거나 **구간 취소** 버튼을 누르면 반복이 해제됩니다.
6. 우측 상단 **편집** 버튼으로 편집 모드 진입 후 문장 행을 탭해 편집/삭제를 선택합니다.

## 한계 및 개선점

1. SFSpeechRecognizer는 en-US로 고정되어 있어 타 언어 오디오는 인식 정확도가 낮습니다.
2. 긴 오디오 파일의 경우 분석 시간이 길어질 수 있습니다.
3. 문장 자동 분리 기준(묵음·단어 수·문장부호)이 콘텐츠 유형에 따라 부정확할 수 있어 수동 편집이 필요합니다.
